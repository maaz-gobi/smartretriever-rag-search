# SmartRetriever — Frequently Asked Questions

## General

**What is SmartRetriever?**
A RAG-based document retrieval and intelligence system. It makes large document collections searchable, answerable, and report-ready.

**What is RAG?**
Retrieval-Augmented Generation. The system retrieves relevant source material first, then generates an answer grounded in it — making answers accurate and traceable.

## Capabilities

**What documents can it process?**
PDF and DOCX files.

**Why does it use both vector and keyword search?**
Vector search matches by meaning; keyword search matches exact terms like names and codes. Hybrid search gives you both relevance and precision.

**Are answers backed by sources?**
Yes. Retrieved results are grounded in your actual documents, so answers stay traceable.

**Can it generate reports?**
Yes. SmartRetriever can compile retrieved content into structured, templated reports.

**How large a collection can it handle?**
SmartRetriever is built for large document sets, not just single files.

## Deployment

**How is it deployed?**
SmartRetriever ships with Docker for portable, consistent deployment across environments.
